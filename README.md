# atividade-pagina-lista-tarefas-localstorage
TO-DO LIST - Aplicação de Lista de Tarefas com LocalStorage

Objetivo: 
- Desenvolver uma aplicação web simples para gerenciar uma lista de tarefas diárias utilizando o localStorage do navegador.

Requisitos:
- Cadastro de Tarefas: Permitir que o usuário adicione novas tarefas na lista.
- Armazenamento Permanente: As tarefas devem ser salvas no localStorage, garantindo que permaneçam mesmo após o fechamento do navegador.
- Remoção de Tarefas: Possibilitar a exclusão de tarefas específicas da lista.
- Limpeza Completa: Incluir a opção de limpar todas as tarefas armazenadas.
- Interface Amigável: Exibir a lista de tarefas de forma clara e organizada na tela utilizando CSS e responsividade.

Critérios de Avaliação:
- Uso correto do localStorage para armazenar, recuperar e remover tarefas.
- Funcionalidade completa dos botões (adicionar, remover e limpar tarefas).
- Boas práticas de programação e clareza no código.
- Criatividade na interface e experiência do usuário.
